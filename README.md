# Mapa drogowa wdrożenia AI

Interaktywna, polska mapa drogowa wdrożenia AI w organizacji: cztery fazy (Fundament, Pilotaż, Wdrożenie, Integracja), bramki decyzyjne, lista kontrolna z zapisem postępu w przeglądarce i kalendarz regulacyjny (AI Act, ustawa krajowa).

- `index.html` - cała strona (styl Quantica Lab, bez kroku budowania, działa z `file://`)
- `roadmap.js` - treść; edytuj ten plik, strona renderuje go sama
- `assets/` - logo i favicon

Skróty: `1`-`4` fazy, `0` góra, `P` przegląd, `R` regulacje, `?` pomoc. Sonda DOM: `window.ROADMAP_CHECK()`.
